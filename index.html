LGU Assistant — RAG Chatbot

A retrieval-augmented chatbot answering student queries over university documents. ChromaDB vector store, CrossEncoder reranking, Groq LLM inference, deployed as an installable PWA.

  • Scraped & chunked hundreds of pages of university docs (PDFs, DOCX, web pages) into a structured knowledge base
  • Two-stage retrieval — SentenceTransformer similarity search, then CrossEncoder reranking — for more accurate top-k context
  • Firebase Authentication + installable PWA so students log in and use it like a native app
  • Swapped between llama-3.3-70b-versatile and llama-3.1-8b-instant to work around Groq rate limits in production

FaceTrace — Recognition Engine

The core face-recognition SDK powering SmartAttend. ArcFace/FaceNet embedding pipeline with MediaPipe pose enforcement for multi-angle enrollment — built as a reusable module with a live cosine-similarity math demo.

// 03 — METHOD

How I Work

Same four steps whether I'm architecting a RAG pipeline or a packaging dieline — only the tools change.

01

Understand the Constraint

What does the system actually need to do — retrieve accurate context, verify a real identity, fit a die-line, sell on a shelf? Start with the real problem, not the tool.

02

Architect / Sketch

For software: data flow, storage, retrieval strategy. For design: structure, hierarchy, brand system. Plan before touching code or Illustrator.

03

Build End-to-End

Backend, frontend, deployment — or concept, mockup, print-ready file. I ship the whole thing myself, solo, not just a slice of it.

04

Ship & Iterate

Deploy it, watch how it's actually used or how it actually looks in-hand, and fix what the real world reveals that planning didn't.
